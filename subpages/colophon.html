Colophon

A note on typography, palette, ornament, and stack.

Hand-written static HTML, CSS, and a little vanilla JavaScript. No framework, no build step beyond a small Python search-index generator. Set to read like an old book printed onto a screen.

Typography

body
et-book — Bonnie Mae Dawson, for Tufte's books.
mono
Inconsolata — Raph Levien.
headings
Upright serif, sentence case; a fading gilt rule beneath each.

Palette

Four tokens, named for the materials of an incunable. Light value (daylit page) and dark value (candlelit page).

vellum
#f6efdf #0b0907 the page.
walnut
#1a140b #f0e2c0 iron-gall ink.
gilt
#8a5a14 #d4a649 links, drop-caps, heading rules.
vermilion
#8c2b1a #c4593a rubric — ornament and Latin.

Ornaments

One glyph: the quincunx ✣, set in vermilion — rubrica — to open each section and close each long-form post.

Stack

markup
semantic HTML, one file per page.
styles
a single CSS file with custom-property tokens.
scripts
vanilla JS — theme toggle, BibTeX clipboard, Ctrl/Cmd+K search.
math
MathJax.
